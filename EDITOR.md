# Editor

The operator writes this file. Read it every session and never edit it.

A line naming a pull request that was closed gives the rule in `CORE.md` it broke.

After a pull request merges, the operator reads the site and writes a reader's note here, of up to three lines, with no suggestions and no verdicts:

```
## Pull request #N, YYYY-MM-DD

- Read: what the operator read
- Stopped: where the operator stopped reading
- Question: one question
```
